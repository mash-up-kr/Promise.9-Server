# 링크 검색 점수 산정

`GET /links?q=...` 검색 결과의 `score` 계산 방법. (코드: `link.repository.ts` `searchHybrid`)

<br>

## 점수 = 코사인 유사도 + 키워드 가산점

```
score = 코사인유사도 + (검색어 정확 포함 시 가산점)
      = [1 − (링크 임베딩 <=> 쿼리 임베딩)]  +  (ILIKE 일치면 +0.3, 아니면 0)
```

- 코사인 유사도: 쿼리와 링크를 같은 임베딩(OpenAI `text-embedding-3-large`)으로 벡터화해 비교. `<=>` 는 pgvector 코사인 거리. **1에 가까울수록 유사**.
- 키워드 가산점(`LINK_SEARCH_KEYWORD_BOOST = 0.3`): 검색어가 제목·도메인·URL·요약·메모에 **포함**되면(공백 제거·소문자 정규화 후 부분일치) 유사도에 더한다. 의미가 비슷한 것들 사이에서 검색어를 정확히 담은 링크를 위로 끌어올리는 용도. 최종 점수는 **1로 클램프**.

<br>

## 순서 정하는 법

1. **벡터 후보**: 코사인 유사도 높은 순 상위 50개(`LINK_SEARCH_CANDIDATE_LIMIT`).
2. **키워드 후보**: `q`가 제목·도메인·URL·요약·메모에 ILIKE 부분일치하는 링크 최대 50개.
3. 두 후보를 합집합으로 모아, 각 링크의 `score`(유사도 + 가산점)를 계산하고 **내림차순 정렬** 후 `limit`개로 자른다.

<br>

## score 값

- **벡터+키워드 둘 다**: 유사도 + 0.3 (최대 1). 검색어를 정확히 포함한 의미 유사 링크 → 최상위.
- **벡터만**: 코사인 유사도 그대로.
- **키워드만(임베딩 없음)**: 유사도를 0으로 보고 가산점만 → 0.3.
- **일반 목록(검색 아님)**: `null`.
- 응답에는 소수점 5자리로 반올림해 내려준다.

<br>

## 튜닝 포인트

- 정확 일치를 더/덜 띄우려면 `LINK_SEARCH_KEYWORD_BOOST` 조정(현재 0.3).
- 후보 수는 `LINK_SEARCH_CANDIDATE_LIMIT`(현재 50).
- 키워드 매칭은 쿼리·컬럼 양쪽을 공백 제거·소문자로 정규화 후 부분일치시킨다(`시드링크`=`시드 링크`, 대소문자 무관). 형태소 분석은 없어 조사·어간 변형은 못 잡는다.
