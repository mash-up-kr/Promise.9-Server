# 팀 공유 스킬

스킬 본문은 레포의 `.agents/skills/`에서 관리합니다. 아래 파일을 직접 읽어 같은 절차로 작업할 수도 있습니다.

| 스킬 | 용도 |
| --- | --- |
| [site-preview-strategy](../../.agents/skills/site-preview-strategy/SKILL.md) | 사이트별 링크 제목·본문·썸네일 수집 전략 조사, 구현, 검증 |

사용 예시:

```text
$site-preview-strategy 이 사이트의 미리보기를 개선해줘: <공개 URL>
```

스킬 목록에 보이지 않는 도구에서는 `.agents/skills/site-preview-strategy/SKILL.md`를 읽고 작업하도록 요청합니다.
