# [정책] 링크 저장

## 1. URL 유효성 검사

- 저장 전 URL 형식 유효성 검사를 수행한다.

## 2. 중복 URL 정책

- 동일 URL은 중복 저장할 수 없다.

## 3. 폴더 지정 정책

- 저장 시 폴더는 최대 1개 선택할 수 있다.
- 폴더를 선택하지 않은 경우 미분류 폴더에 자동 저장된다.
- 저장 후 폴더 변경이 가능하다.

## 4. 링크 일괄 폴더 이동 정책

- 전체, 미분류, 즐겨찾기, 사용자 폴더, 검색 결과 등 링크를 선택한 화면은 서버에서 구분하지 않는다.
- 사용자가 소유한 활성 링크만 이동할 수 있으며 최근 삭제된 링크는 이동할 수 없다.
- 한 요청에는 링크를 최대 100개까지 전달할 수 있다.
- 중복된 링크 ID는 서버에서 제거하고 한 번만 처리한다.
- 목적지는 사용자가 소유한 폴더 또는 미분류(`folderId=null`)다. 전체, 즐겨찾기, 최근 삭제는 실제 폴더가 아니므로 목적지가 될 수 없다.
- 이미 목적지에 있는 링크는 성공한 no-op으로 처리하고 수정 시각을 변경하지 않는다.
- 링크 하나라도 없거나, 삭제됐거나, 다른 사용자 소유이면 전체 요청을 실패시킨다.
- 목적지 폴더가 없거나 다른 사용자 소유여도 전체 요청을 실패시킨다.
- 모든 검증과 이동은 하나의 DB transaction에서 실행하며 부분 성공을 허용하지 않는다.

## 5. 메타 데이터 수집

- 저장 시 제목, 출처, 대표 이미지를 자동 수집한다.
- 수집 실패 시 URL만 저장한다.
- 대표 이미지가 없는 경우 기본 이미지를 노출한다.

## 6. 메모 정책

- 메모는 선택 입력 항목이다.
- 최대 500자까지 입력할 수 있다.

## 7. 저장 기본값

- 메모 기본값 : null
- 폴더 선택 기본값 : "미분류"

## 8. 저장 일시

- 링크 저장 시 저장 일시를 기록한다.
