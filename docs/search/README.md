# Search

`GET /links?q=...` 링크 검색이 어떻게 동작하는지 참고하는 문서다.

| 문서                                                | 내용                                                                  |
| --------------------------------------------------- | --------------------------------------------------------------------- |
| [벡터 검색 구조](./link-vector-search.md)           | pgvector 도입, 임베딩 컬럼, 코사인 유사도 계산, 벡터 인덱스 정책      |
| [검색 점수 산정](./link-search-scoring.md)          | 키워드 가산점과 벡터 유사도를 합치는 점수 공식, 후보 수집·정렬·커서   |

검색은 벡터(의미) 검색과 키워드(부분일치) 검색을 합친 하이브리드 방식이다.
두 경로에서 후보를 각각 모아 하나의 점수로 정렬한다.
