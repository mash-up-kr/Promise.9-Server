## 요약

X 게시물의 링크·본문 형식이 조금 달라도 제목과 이미지를 수집하도록 조건을 완화합니다. PR #129 리뷰에서 지적된 본문 잘림과 사진 순번 선택 문제도 수정합니다.

## 변경 내용

- 게시물 ID 뒤의 쿼리·fragment·슬래시·미디어 경로 허용
- 본문 파싱 실패 시 메타 설명으로 대체하고, 확보한 자체 이미지는 유지
- 반복 게시물과 시각 뒤의 반응 수를 확인해 본문 일정 문구가 잘리는 문제 수정
- `/photo/N`을 배열 순서가 아닌 실제 사진 링크로 선택
- 지정 사진이 없거나 빈 링크만 있으면 확보된 자체 미디어 사용

자체 이미지가 없으면 `null`, 정상 수집은 TinyFish 1회라는 정책은 유지합니다.

## 검증

- 실제 X 링크 8건 및 사진 1·2·3번·인용 포함 사진 순번 재검증
- 사진 순서 변경·빈 사진 링크·본문 일정 문구·반복 게시물 검증
- 관련 테스트 246개, 빌드·린트 통과

메타 설명으로 대체하면 본문이 짧아질 수 있습니다. 지정 사진을 확보하지 못한 경우 대체 이미지는 요청한 순번과 다를 수 있습니다.
