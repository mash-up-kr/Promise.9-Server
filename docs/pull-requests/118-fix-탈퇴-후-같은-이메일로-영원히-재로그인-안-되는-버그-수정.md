## 🔍 상세 내용
**Before**
```ts
const existingUser = await tx.query.users.findFirst({
    where: eq(users.email, input.email),
})
```
탈퇴한 유저의 `users` row(email 컬럼은 삭제되지 않음)가 그대로 매칭되어 `EMAIL_ALREADY_REGISTERED`(409)를 던지고, 신규 가입 INSERT까지 도달하지 못했습니다.

**After**
```ts
const existingUser = await tx.query.users.findFirst({
    where: and(eq(users.email, input.email), isNull(users.deletedAt)),
})
```
탈퇴한 계정은 조회에서 제외되어, 같은 이메일로도 정상적으로 재가입(신규 `users` row 생성)됩니다.
