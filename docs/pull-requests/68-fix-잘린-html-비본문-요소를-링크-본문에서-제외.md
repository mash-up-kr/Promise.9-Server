## 📌 개요

링크 페이지는 원본 HTML 응답을 최대 1MB까지만 읽습니다. 이 과정에서 `script`, `style`, `noscript` 요소가 닫히기 전에 HTML이 잘리면, 닫는 태그를 기준으로 동작하던 기존 정규식이 해당 요소를 제거하지 못하는 문제가 있었습니다.

그 결과 YouTube의 `ytInitialData`처럼 요약과 태그 생성에 필요하지 않은 대규모 실행 데이터가 `CONTENT`에 포함됐습니다. 닫히지 않은 비본문 요소도 수집된 문서의 끝까지 제거하도록 본문 정제 로직을 보완했습니다.

## ✅ 작업 내용 및 변경 사항

- [x] 닫히지 않은 `script`를 문서 끝까지 본문에서 제외
- [x] 닫히지 않은 `style`을 문서 끝까지 본문에서 제외
- [x] 닫히지 않은 `noscript`를 문서 끝까지 본문에서 제외
- [x] 닫히지 않은 HTML 주석을 문서 끝까지 본문에서 제외
- [x] 정상적으로 닫힌 요소 뒤의 본문을 기존과 동일하게 보존
- [x] 세 태그의 정상 종료와 중간 잘림에 대한 회귀 테스트 추가
- [x] 신규 의존성 없이 기존 정규식 기반 구조 유지

## 💬 리뷰어에게

이번 PR은 원본 HTML 수집 상한 때문에 잘린 비본문 요소가 LLM 입력에 포함되는 문제만 독립적으로 수정합니다.

아래의 개선 작업을 해도 좋을 것 같아여

- 사이트 공통 UI와 실제 본문을 구분하는 별도의 추출 체계 도입
- 주요 정보 보존 여부를 검증한 뒤 `CONTENT` 16,000자 상한 하향
- 요약과 태그를 하나의 Structured Output 호출로 생성해 동일한 `CONTENT`를 두 번 전송하는 구조 개선

요약·태그 통합 호출은 본문을 추가로 제거하지 않고 입력 중복을 줄일 수 있습니다.

## 🔍 상세 내용

### 본문 수집 및 정제 순서

본문은 다음 순서로 처리합니다.

1. HTTP 응답에서 원본 HTML을 최대 1MB까지 수집합니다.
2. 수집된 HTML 전체에서 주석과 `script`, `style`, `noscript`를 제거합니다.
3. 나머지 HTML 태그를 제거하고 HTML entity와 공백을 정리합니다.
4. 정제된 `CONTENT`를 최대 16,000자로 제한합니다.

따라서 `CONTENT` 16,000자 상한은 태그 제거 이후에 적용됩니다. 다만 태그 제거보다 먼저 원본 HTML 1MB 수집 상한이 적용되므로, 수집된 문서에는 시작 태그만 있고 닫는 태그가 없을 수 있습니다.

이번 변경은 각 비본문 요소의 닫는 태그가 없을 때 문서 끝을 해당 요소의 끝으로 취급합니다. 무제한으로 원본 응답을 받은 뒤 정제하지 않고도 1MB 수집 상한을 유지하면서 잘린 실행·스타일 데이터가 `CONTENT`에 포함되지 않도록 합니다.

```text
원본 HTML 응답
→ 최대 1MB까지 수집
→ 주석 및 script/style/noscript 제거
→ 나머지 HTML 태그·entity·공백 정리
→ CONTENT 최대 16,000자 적용
```

### YouTube `CONTENT`에 포함되던 내용

변경 전 YouTube `CONTENT`에는 크게 두 종류의 불필요한 정보가 포함됐습니다.

첫 번째는 화면에 표시되는 사이트 공통 정보입니다.

- 보도자료, 저작권, 광고, 개발자, 약관, 개인정보처리방침
- Google LLC 주소와 사업자 정보
- 불법촬영물 신고 및 상품 판매 관련 안내

두 번째는 웹 화면 구성과 추적에 사용되는 대규모 인라인 스크립트입니다.

- `ytInitialData`
- `serviceTrackingParams`
- `visitor_data`
- `trackingParams`, `clickTrackingParams`
- 화면 renderer 설정
- 추천 영상과 navigation/prefetch 데이터

이번 PR에서는 두 번째에 해당하는 스크립트 데이터를 제거합니다. 첫 번째 사이트 공통 정보는 개선 후에도 약 444자의 `CONTENT`로 남으며, 별도 본문 추출 작업에서 다룰 예정입니다.

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| `CONTENT` 길이 | 16,000자 | 444자 |

| `ytInitialData` 포함 | 포함 | 제외 |

스크립트 데이터가 제거되면서 `CONTENT` 길이가 약 97% 감소했습니다. 영상 제목과 설명은 기존과 동일하게 별도 필드로 전달됩니다.
