## PR Body

## 변경 내용

기존 검색은 관련성이 낮은 벡터 후보도 결과에 포함했습니다. 제목·AI 요약의 키워드 비중을 높이고, 키워드가 일치하지 않는 후보에 임계값을 적용해 무관한 결과의 노출을 줄였습니다.

- 제목·AI 요약의 키워드 가중치 확대
- 제목·요약·태그·폴더 중 하나라도 키워드가 일치하면 해당 후보 유지
- 키워드가 일치하지 않으면 벡터 점수가 **후보 평균 + 표준편차**를 초과할 때만 노출

## 평가 방법

마스터 유저의 활성 링크 **1,553개**를 대상으로 일반 검색어 61개와 실제 폴더명 8개, 총 **69개 검색어**로 평가했습니다. 제목·요약 키워드, 태그, 자연어, 무관 질의를 포함했습니다.

일반 검색어 중 대표 12개와 정책 선택에 사용하지 않은 별도 검증용 6개는 결과의 관련성도 확인했습니다. 각 검색어의 **상위 최대 9개 결과를 하나씩** 다음과 같이 판정했습니다.

- **직접 관련:** 검색 대상과 목적을 직접 충족
- **인접 주제:** 검색 의도의 일부나 주변 주제에 해당
- **무관:** 검색 목적과 관련 없음

## 검색 결과 개수 변경

기존에는 최소 관련성 기준 없이 상위 결과를 반환해, 평가한 모든 검색어에서 결과가 9개 이상 나왔습니다.

임계값을 추가한 후에는 키워드가 일치하지 않고 벡터 점수도 기준 이하인 후보를 제외합니다. 그 결과 **전체 69개 검색어 중 25개에서 검색 결과가 9개 미만으로 줄었습니다.**

| 평가 대상 | 변경 전: 결과가 9개 미만인 검색어 | 변경 후: 결과가 9개 미만인 검색어 |
| --- | ---: | ---: |
| 일반 검색어 61개 | 0개 | **24개** |
| 폴더명 검색어 8개 | 0개 | **1개** |
| 일반 검색어 중 대표 12개 | 0개 | **6개** |
| 일반 검색어 중 별도 검증용 6개 | 0개 | **2개** |

대표 12개와 별도 검증용 6개는 일반 검색어 61개에 포함됩니다.

## 상위 검색 결과의 관련성 (폴더 우선 처리 제거 전 평가)

아래는 폴더 우선 처리가 포함됐던 이전 평가 기록입니다. 현재는 해당 우선 처리를 제거했으므로 상위 결과의 관련성 수치는 현재 정렬에 대한 측정값이 아닙니다. 결과 개수는 같은 임계값을 사용하므로 변하지 않습니다.

검색어마다 상위 최대 9개 결과를 **각각 판정한 뒤 합산**했습니다. 예를 들어 결과 9개 중 직접 관련이 3개라면, 아래 표에 직접 관련 **3건**으로 반영됩니다. 같은 링크도 다른 검색어의 결과에 나오면 별도로 평가합니다.

| 평가 대상 | 판정 | 변경 전 | 변경 후 |
| --- | --- | ---: | ---: |
| 대표 검색어 12개 | 평가한 결과 총수 | 108건 | 88건 |
| | 직접 관련 | 28건 | **29건** |
| | 인접 주제 | 53건 | 34건 |
| | 무관 | 27건 | **25건** |
| 별도 검증용 검색어 6개 | 평가한 결과 총수 | 54건 | 42건 |
| | 직접 관련 | 8건 | **8건** |
| | 인접 주제 | 26건 | 21건 |
| | 무관 | 20건 | **13건** |

변경 후에는 결과가 9개보다 적은 검색어가 있어 평가한 결과 총수도 줄었습니다. 직접 관련 결과는 유지하거나 늘면서 무관한 결과가 줄었지만, 인접 주제 결과도 함께 감소했습니다.

## 검증

- 실제 DB 평가는 5.6 terra가 수행한 기존 69개 검색어 기록이며, 이번 폴더 우선 처리 제거 후 DB 평가는 재실행하지 않았습니다.
- 폴더 필터가 별도로 있으므로 폴더명 완전 일치의 강제 우선순위를 제거했습니다. 네 필드의 키워드 일치 보호와 벡터 임계값은 유지합니다.
- 평가 규모·구성 변경 사유·판단 근거는 [평가 기록](https://github.com/mash-up-kr/Promise.9-Server/blob/fix/search-relevance-threshold/docs/search/link-search-evaluation.md)에 남겼습니다. 평가용 테스트·스크립트는 커밋에서 제외했습니다.
- 폴더 우선 처리 제거에 맞춰 기존 테스트를 갱신했고, 5.6 terra가 검색 테스트 두 파일 **20개 통과**를 확인했습니다.
