## 📌 개요
탈퇴 후 같은 이메일로 재가입할 때, 활성 회원 조회는 통과하지만 전역 `users_email_unique` 제약 때문에 INSERT가 실패하던 문제를 수정합니다. 활성 회원에게만 이메일 유니크 제약을 적용해 PR #118의 조회 조건과 DB 제약을 일치시킵니다.

## ✅ 작업 내용 및 변경 사항
- [x] `users` schema에 `deleted_at IS NULL` 조건의 `users_active_email_unique` partial unique index 적용
- [x] 기존 전역 제약을 교체하는 `0012_users_active_email_unique` migration 추가
- [x] Drizzle snapshot과 journal 갱신

## 💬 리뷰어에게
탈퇴 계정 행은 유지하고, 재가입은 기존 행 복원이 아닌 새 계정 생성 흐름을 따릅니다. 활성 회원 간 이메일 중복은 계속 차단됩니다.

## 🔗 관련 이슈
- #118 후속 수정

## 🔍 상세 내용
기존 전역 UNIQUE 제약을 제거하고 활성 행만 대상으로 유니크 인덱스를 생성합니다.

검증:
- `bun run build` 통과
- 변경 schema ESLint 통과
- `git diff --check` 통과

실제 소셜 로그인 E2E는 실행하지 않았습니다.
