## PR Body

## 요약

X 게시물 제목이 계정명으로 나오거나 부모 글·댓글 사진이 썸네일에 섞이는 문제를 개선합니다. 대상 게시물을 TinyFish 1회로 수집하고 본문 첫 줄을 제목으로 사용합니다.

## 변경 내용

- 대상 게시물의 본문·사진·영상 포스터만 수집하고 `/photo/N` 순번 반영
- 자체 이미지가 없으면 `null`, 프로필 링크는 계정 대표 이미지 사용
- 작성자·게시 시각·반응 수·영상 재생 표시 제거
- 기존 `normalizeContent` 구조를 유지하고 수집 범위 옵션 추가
- 본문 식별 실패를 기존 재시도 흐름에 연결

## 검증

- 공개 URL 11건에서 사진·답글·영상·인용·프로필 케이스 확인
- 최종 사진·텍스트·인용 표본에서 요청 1회 및 이미지 선택 재검증
- 전체 테스트 474개, 빌드·린트·GitHub CI 통과

라이브 다시보기의 만료 이미지 URL은 지원하지 않습니다. 다른 언어의 시각 표기와 혼합 미디어는 추가 검증이 필요합니다.
