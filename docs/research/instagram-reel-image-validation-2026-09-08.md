# Instagram 게시물·릴스 수집 비교 검증 — 2026-09-08

## 최종 동작

일반 게시물과 피드는 별도 URL 유형이 아니다. 개별 피드 게시물은 `/p/{shortcode}/`이며, 이미지 게시물과 캐러셀을 나누어 확인했다. 계정 프로필/피드 진입 URL도 별도로 확인했다.

| 케이스 | TinyFish 조회 | 제목 | DB `metadata.description` / AI 입력 | `content` | 이미지 |
| --- | --- | --- | --- | --- | --- |
| 일반 이미지 피드 `/p/` | `/p/{id}/embed/captioned/` 1회 | 캡션 첫 줄, 최대 100자 | 작성자 캡션만, 최대 2,000자 | `null` | 대표 이미지 1개 |
| 캐러셀 피드 `/p/` | `/p/{id}/embed/captioned/` 1회 | 동일 | 동일 | `null` | 대표 이미지 1개, 전체 슬라이드 수집 아님 |
| 릴스 `/reel/`, `/reels/` | `/reel/{id}/embed/captioned/` 1회 | 동일 | 동일 | `null` | 대상 미디어 ID를 검증한 릴스 표지 1개 |
| 계정 프로필/피드 진입 `/{username}/` | 원본 URL 1회, 기존 동작 | 원본 제목 | 원본 설명 | 원본 본문 | 프로필 이미지 |

TinyFish 원본 응답의 `title`은 `Instagram`, `description`은 null이었다. `/embed/captioned/`의 `text`에서 캡션 구간을 추출한다. 좋아요·댓글 수, 계정·날짜 등의 메타데이터와 UI 문구는 DB 설명에 포함하지 않는다. 공통 AI 프롬프트는 `description`을 사용하며 `content: null`이면 CONTENT 항목을 생략하므로 전용 AI 처리기는 없다.

캡션이 없거나 경계를 식별하지 못하면 제목·설명·본문을 null로 반환하고 AI 분석 불가를 표시한다. 이미지는 독립적으로 선택한다. `/tv/`도 코드상 captioned 경로를 사용하지만 이번 실제 표본에는 포함하지 않았다.

## 재측정 조건

- 비교: 변경 전 원본 URL 수집 `4c0988f`와 최종 PR 코드 `95e75df`의 실제 `LinkContentService.preview()` / `collect()`.
- 표본: 이미지 피드 1건, 캐러셀 피드 1건, 릴스 4건. URL × 경로 × 버전마다 3회 반복해 총 72회. 프로필은 버전별 preview/collect 1회씩 4회 추가해 총 76회.
- 기존/변경 버전 순서를 번갈아 실행했으며 동시 요청 없이 순차 측정했다.
- 서비스 호출 시작부터 반환까지 측정했다. 이미지 URL의 DNS 검증은 포함하며, 반환 후 이미지 HEAD 확인 시간은 제외한다. DB 저장·큐 대기·실제 LLM 생성 시간은 포함하지 않는다.
- 두 버전 모두 실제 TinyFish 클라이언트 설정 `ttl: 3600`, `per_url_timeout_ms: 20000`을 사용했다. 캐시 초기화나 캐시 적중 여부 확인은 하지 않았으므로 캐시 미사용 성능이나 운영 성능 보장으로 해석하지 않는다.
- 대표값은 성공한 호출의 중앙값이다. 경로/버전당 18회, 개별 URL당 3회를 시도했다. 기존 preview는 17/18회 성공했고 나머지 경로/버전은 18/18회 성공했다. 감소율은 `(기존 중앙값 - 변경 중앙값) / 기존 중앙값`이다.
- 실행 시각(UTC): `2026-09-08T14:30:39.107Z` ~ `2026-09-08T14:37:58.897Z`.
- 문자 수는 서비스 제한 기준과 같은 JavaScript UTF-16 길이다.

- 최종 방식 36/36회: TinyFish 단일 captioned 요청, 캡션 기반 제목과 이미지 반환, 이미지 HEAD HTTP 200 및 image Content-Type 확인.

- 최종 collect 18/18회: 기존에 확인한 캡션과 일치, `content: null`, AI 분석 가능 상태 확인. 캡션은 124~1,833자였으며 2,000자 초과 실제 표본은 이번에 포함하지 않았다.
- 표본별 첫 collect에서 변경 캡션이 기존 원본 description에도 존재하는지 공백·Markdown 이스케이프를 정규화해 대조했다. 6/6건 일치했다.
- 실제 수집 결과 18건으로 공통 요약·태그 프롬프트를 각각 생성해 36/36건에서 DESCRIPTION 포함 및 CONTENT 항목 생략을 확인했다. 실제 LLM 호출과 DB 쓰기는 수행하지 않았다.

## 프로필 확인

계정 프로필은 captioned 전환 대상이 아니다. `https://www.instagram.com/nasa/`를 추가 조회해 원본 경로 유지와 프로필 제목·설명·본문·이미지를 확인했다. 계정 피드의 개별 게시물을 모두 수집하는 기능은 아니다.
